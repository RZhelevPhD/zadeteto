# ЧАСТ 4: NAMING КОНВЕНЦИЯ ЗА A/B ТЕСТВАНЕ

```
Формат: ZD-B2B-{STAGE}-{TYPE}{NUMBER}

Етапи:     AW = Awareness, CO = Consideration, CV = Conversion
Типове:    Q = Question, C = Command, S = Statement, L = List,
           N = Narrative, P = Provocative
Примери:   ZD-B2B-AW-Q01, ZD-B2B-CV-P03, ZD-B2B-CO-L04
```

**Как да тествате:**
1. Пуснете 5-6 хука с едно и също body content → намерете winning hook
2. Вземете winning hook → тествайте с 2-3 различни body-та
3. Вземете winning combo → тествайте 3-те CTA варианта
4. Scale winning creative

# БЕЛЕЖКИ ЗА ИЗПЪЛНЕНИЕ

- **Meta:** Text posts и carousels работят най-добре за B2B. Stories за urgency/countdown.
- **YouTube:** Video scripts (AD 2, AD 5) са за pre-roll или in-feed. Първите 5 сек = хукът.
- **A/B testing:** Пускайте minimum 3 хука на ad body. Data решава, не мнения.
- **Визуали:** Използвайте brand цветовете (purple #7c4dff, mint #4caf6a, gold #f5d76e). Бадж визуалите са ключови.
- **Retargeting:** Хората, които са видели awareness ad-ове, получават consideration/conversion ads.
