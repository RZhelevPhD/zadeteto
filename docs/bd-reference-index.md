## Business Context

Before using this index, every `bd` agent must first read `docs/bd-context.md` — the user's outreach reality (what they sell, ICP, pricing, objections they actually hit, output language, tone preferences). Coaching must be grounded in *their* business, not generic BD theory.

## Competitor Watch List

`docs/competitors.md` tracks competitors and category-adjacent platforms. **Read it before any outreach to a prospect who is likely listed on or affiliated with a competitor** — the entry includes reputation risks, historical actions (scandals, revoked awards, pivots), and the prospect's likely current alternatives. This context changes openers, Humanising Questions (BC1 M11), and Negative-Socratic Questions (BC1 M16–17). When unsure, do a fast grep through `docs/competitors.md` for the prospect's name before drafting outreach.

## Rules for Subagents

- **Scope lock:** only Read / Grep / Glob inside your assigned folder. If the orchestrator asks you about a framework that lives in another subagent's folder, respond: "Out of scope — route to `bd-{other}`."
- **Never reproduce full transcripts.** Cite module filename + framework name + your summarized point.
- **Always ground findings in a named BD framework.** "Opener is weak" is useless. "Opener has no Pattern Interrupt (Bootcamp M14), prospect's Adult ego state wasn't engaged (Bootcamp M7)" is useful.
- **Return the standardized format** (see orchestrator `bd.md` for the template).
